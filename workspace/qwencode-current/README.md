# QwenCode Current Workspace

这是 QwenCode 当前轮次的直接工作入口。

## 你应该先看什么

1. `workspace/qwencode-current/INSTRUCTIONS.md`
2. `workspace/qwencode-current/REPORT_TEMPLATE.md`
3. 文档中列出的主仓库治理文件

## 这个工作区的用途

- 汇总本轮直接执行指令
- 指向必须阅读的正式治理文档
- 约束本轮回报格式
- 作为 Codex 和 QwenCode 之间的稳定交接面

## 边界说明

- 本目录是“执行入口”和“反馈入口”，不是项目唯一代码目录
- 真实代码、测试和 Stata 产物仍然应按主仓库文档要求写入对应位置
- 本目录不替代 `docs/`，只负责让 QwenCode 快速进入当前轮次
