# Stata 对齐规范

## 1. 目标版本

- 默认目标版本：Stata 17
- 当前验证路径基准：`D:\Software\Stata17`

若后续切换 Stata 版本，必须新增 ADR，并更新本文件中的差异说明。

## 2. v1 命令映射

### 已承诺

- `regress`
- `regress, vce(robust)`
- `regress, vce(cluster clustvar)`
- `xtreg, fe` 的单向 FE 核心估计行为

### 仅做架构预留

- `areg`
- 双向 FE
- `reghdfe` 风格多维吸收

### 明确不纳入 v1

- `logit`
- `probit`
- `poisson`
- `xtreg, re`
- `ivregress`
- GMM
- 多维 cluster

## 3. 样本筛选规则

v1 采用以下硬规则：

- 任何参与估计的变量出现缺失，观测行必须被剔除
- 因变量、自变量、cluster 变量、FE 变量都参与样本判定
- 样本掩码必须被记录到结果对象

## 4. 常数项规则

- `OLS` 默认加常数项
- `FixedEffectsOLS` 默认不加常数项
- 若 FE 模型要求保留常数项语义，需通过投影后可解释的方式实现，不得产生重复完全共线列

## 5. 共线性处理

- 共线列必须被显式识别
- 被剔除变量必须在结果或 diagnostics 中可追踪
- 不允许依赖底层线性代数库的隐式行为而不记录结果

## 6. 自由度规则

至少需要对齐以下维度：

- `df_model`
- `df_resid`
- `F` 统计量使用的分子分母自由度
- cluster 情况下的小样本修正规则

如无法直接从 Stata 内部源码得到结论，必须通过帮助文档、`e()` 返回值与对照样例联合反推，并以测试固定下来。

## 7. 权重语义

v1 仅公开支持 `aweight` 语义，且必须满足：

- 文档说明其数学含义
- 给出与未加权 OLS 的差异说明
- 有独立双跑测试样例

其他权重类型在未写明前都视为不支持。

## 8. Cluster 修正规则

- v1 仅支持单聚类
- `vce(cluster clustvar)` 的修正因子、群组数、自由度处理必须明确记录
- 单例群组与极少群组的行为必须由测试样例覆盖

## 9. 严格一致与统计意义等价

### 严格一致

默认要求以下字段在预设浮点容差内一致：

- 系数
- 标准误
- `t` 统计量
- `p` 值
- 协方差矩阵
- `R-squared`
- `F` 统计量
- 自由度

### 统计意义等价

仅在下列情况下可接受：

- 差异来自不同但合理的数值路径
- 统计推断结论不变
- 样例元数据明确声明容差与原因
- 已由宏观架构层确认接受

## 10. 源码与规则研究优先级

应优先研究：

1. `regress` 相关帮助文档和返回结果
2. `xtreg, fe`
3. `areg`
4. `vce(robust)` 与 `vce(cluster)` 的自由度和修正规则
5. 能公开获得的 ado、技术说明与官方示例
