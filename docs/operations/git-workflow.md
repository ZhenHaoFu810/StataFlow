# Git 工作流

## 分支角色

- `main`
  - 稳定主线
- `codex/<topic>`
  - Codex 维护文档、治理、review 与架构层工作
- `claude/<topic>`
  - Claude Code 实施具体代码、测试、数据夹具或研究任务

历史 `qwen/<topic>` 分支可保留，但不再作为默认命名。

## 提交粒度

- 文档治理变更
  - 尽量单独提交
- 研究档案与本地镜像整理
  - 可与同一轮文档治理一起提交
- 代码实现与测试
  - 由执行代理在独立分支提交

## 标准流程

1. Codex 在 `codex/<topic>` 分支维护路线图、研究框架、门禁和任务卡。
2. Claude Code 从最新稳定基线创建 `claude/<topic>` 分支。
3. Claude Code 按任务卡实施代码、测试与证据回填。
4. Codex 审查结果并决定通过、返工或升级。
5. 通过后再决定是否合并回 `main`。

## 禁止事项

- 不得把未经审查的实现直接合并进 `main`
- 不得在同一提交中混杂无关命令族实现
- 不得绕过文档与研究档案直接进入大规模实现
