# 阶段门禁

## 1. 单轮任务完成定义

一轮任务被视为完成，至少需要：

- 执行代理已提交结构化回报
- 研究档案、测试样例与实现一致
- synthetic 样例通过
- real-data 样例通过
- 全量回归测试通过
- Codex 已确认无未解释偏差

## 2. 必须返工的情形

出现以下任一情况，必须打回：

- 关键统计量未与 Stata 对齐
- 真实数据样例缺失
- 研究档案与测试结论冲突
- backlog 或样例目录状态先于门禁推进
- 完成报告把未对齐差异写成“可接受”但未获裁决

## 3. 允许推进下一项的条件

只有在当前条目被明确标记为 `done` 后，才允许开放下一项。

`done` 的最低含义：

- synthetic 与 real-data 双线验证都已完成
- 研究档案完整
- 文档状态一致
- 无待决 ADR

## 4. 阶段完成定义

某一阶段被视为完成，至少需要：

- 阶段目标涉及的命令族条目都已通过门禁
- 该阶段核心研究档案已建立
- 真实数据验证库中至少有对应条目
- 当前阶段没有“名义完成、实际待裁决”的条目
