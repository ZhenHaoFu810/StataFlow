# Phase 2 执行手册：Weights And Single FE

## 目标

实现并验证 `aweight` 与单向 FE，并为后续吸收式固定效应扩展建立稳定内部接口。

## 前置条件

- Phase 1 已完成
- 线性核心 API 稳定
- 样本筛选和 schema 已被验证

## 任务序列

### 任务 1：`aweight` 语义落地

需要完成：

- 文档化 `aweight` 的数学含义
- 在估计层与协方差层接入权重
- 将 `weight_type="aweight"` 写入结果对象

需要新增的测试：

- `p2_aweight_basic`
- 至少一个与未加权结果显著不同的样例

验收标准：

- `aweight` 结果与 Stata 对齐

禁止事项：

- 不得在未定义语义前实现其他权重类型

### 任务 2：单向 FE 基础

需要完成：

- 实现单一 FE 变量的 within 或等价残差化流程
- 记录 FE 元数据
- 保证结果对象字段与 OLS 路径兼容

需要新增的测试：

- `p2_fe_basic`

验收标准：

- FE 系数和关键统计量与 Stata 对齐

禁止事项：

- 不得直接把双向 FE 或高维 FE 塞进同一公开接口

### 任务 3：FE + cluster

需要完成：

- 支持单向 FE 与单聚类共同出现
- 对齐自由度和群组元数据

需要新增的测试：

- `p2_fe_cluster`

验收标准：

- FE + cluster 双跑通过

禁止事项：

- 不得跳过边界样例

## 阶段验收标准

- `aweight` 与单向 FE 完成公开交付
- 对应黄金样例均通过
- 吸收式内部接口的后续扩展点已在文档中记录
