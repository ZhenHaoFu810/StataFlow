# Open-Source Package Manifest

This directory is a release-oriented copy prepared from the broader development workspace.

## Included

- core package source
- public examples
- command support matrices
- release-facing documentation
- validation book and validation scripts
- public datasets used for validation
- generated validation summaries and evidence artifacts
- baseline automated tests that are useful to external users

## Intentionally excluded or minimized

- internal AI task prompts
- iterative review back-and-forth
- development-stage backlog coordination
- most one-off progress logs
- most temporary scripts not needed for release use

## Rationale

The original workspace remains the full development record. This directory is intended to be cleaner, easier to read, and more appropriate for first public release and external review.
