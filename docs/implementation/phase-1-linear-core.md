# Phase 1 执行手册：Linear Core

## 目标

实现并验证 OLS、`vce(robust)`、`vce(cluster)`、样本筛选、常数项和共线性处理。

## 前置条件

- Phase 0 已完成
- 双跑链路稳定
- 结果 schema 已冻结到可开发状态

## 任务序列

### 任务 1：OLS 基础实现

需要完成：

- 实现设计矩阵构造
- 实现 OLS 点估计
- 生成结果对象

需要新增的测试：

- `p1_ols_basic`

验收标准：

- OLS 核心字段与 Stata 对齐

禁止事项：

- 不得将现有库输出直接原样包装为最终结果

### 任务 2：样本筛选与常数项规则

需要完成：

- 明确缺失值剔除顺序
- 实现常数项自动插入
- 记录样本掩码

需要新增的测试：

- 缺失值样例
- 常数项开关样例

验收标准：

- `sample_mask` 与 Stata 样本一致

禁止事项：

- 不得只返回剔除后样本数而不记录掩码

### 任务 3：共线性处理

需要完成：

- 识别共线列
- 记录被剔除变量
- 保证结果字段顺序稳定

需要新增的测试：

- `p1_collinearity_drop`

验收标准：

- 共线性处理行为与 Stata 一致或有批准的统计等价说明

禁止事项：

- 不得静默丢弃变量

### 任务 4：`vce(robust)`

需要完成：

- 实现 robust 协方差
- 对齐相关自由度与展示字段

需要新增的测试：

- `p1_robust_hc1`

验收标准：

- robust 标准误和推断字段对齐

禁止事项：

- 不得仅验证系数

### 任务 5：`vce(cluster)`

需要完成：

- 构造单聚类索引
- 实现 cluster 协方差与修正因子
- 记录群组数与 cluster 元数据

需要新增的测试：

- `p1_cluster_firm`
- 少群组或单例群组边界样例

验收标准：

- cluster 标准误、自由度、群组元数据对齐

禁止事项：

- v1 不得自行扩展到多维 cluster

## 阶段验收标准

- OLS、robust、cluster 均有公开 API
- 所有 P1 样例通过
- 无未解释字段偏差
- backlog 与样例目录已更新状态
