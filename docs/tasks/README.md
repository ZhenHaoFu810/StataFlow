# 派工任务目录

本目录存放由 Codex 签发、供执行代理直接执行的任务卡。

## 任务卡与阶段手册的区别

- 阶段手册
  - 定义一个阶段要做什么
  - 说明边界、验收标准和禁止事项
- 任务卡
  - 定义当前这一轮具体要做什么
  - 写明应修改哪些文件、先补哪些测试、回报哪些证据

## 当前原则

- 后续仍按分块任务推进
- Claude Code 作为默认执行代理
- 当前已开放：
  - `wave-1-task-003-areg-real-data-validation.md`

## 使用规则

- 执行代理每轮开始前必须确认是否存在对应任务卡
- 若任务卡与阶段手册冲突，以任务卡为本轮直接执行依据
- 若没有任务卡，执行代理不得自行拆解大型实现
