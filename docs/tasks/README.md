# 派工任务目录

本目录存放由 Codex 签发、供 QwenCode 直接执行的任务卡。

## 任务卡与阶段手册的区别

- 阶段手册：
  - 定义一个阶段要做什么
  - 说明边界、验收标准、禁止事项和任务序列
  - 存放在 `docs/phases/`
  - 面向阶段管理

- 任务卡：
  - 定义当前这一轮具体要做什么
  - 写明本轮应修改哪些文件、先写哪些测试、执行哪些命令、回报哪些证据
  - 面向直接执行

## 使用规则

- QwenCode 每轮开始前必须先确认是否存在对应任务卡
- 若任务卡与阶段手册冲突，以任务卡为本轮直接执行依据，并将冲突上报给 Codex
- 一个任务卡只对应一个清晰目标，避免把多个独立能力混在同一轮
- 若没有任务卡，QwenCode 只能停在阶段手册层面，不得自行拆解大型工作

## 命名规则

建议命名格式：

- `phase-0-task-001-<topic>.md`
- `phase-1-task-003-<topic>.md`
